Quick Start

Get the platform running locally in 3 commands:

git clone <repo-url> && cd lecture-agentic-ai
cp .env.example .env    # Fill in API keys
docker compose up --build

Services will be available at:

  • Demo UI — http://localhost:3200
  • Orchestrator Admin — http://localhost:3100
  • HAST API + Swagger — http://localhost:8000/docs
  • Temporal UI — http://localhost:8233

LMS Integration

Connect your Learning Management System to submit evaluations automatically:

POST /api/submissions
Authorization: Bearer $HAST_API_KEY
Content-Type: application/json

{
  "submission_type": "assessment",
  "entity_id": "student-12345",
  "content": "Essay text here...",
  "criteria": "Rubric criteria...",
  "context": {"course_id": "CS-101"}
}

The submission enters a Temporal workflow and waits for human review. Poll GET /api/submissions/{id} for status updates.

Review Decision API

Approve, reject, or request revision on any pending submission:

POST /api/submissions/{id}/review
Authorization: Bearer $HAST_API_KEY
Content-Type: application/json

{
  "decision": "approved",
  "reviewer_notes": "Well-structured analysis.",
  "adjusted_score": 85
}

Valid decisions: approved, rejected, revision_requested

Webhook Notifications

Get notified when submissions are ready for review or about to expire:

# Set in .env or docker-compose.yml:
NOTIFICATION_WEBHOOK_URL=https://your-system.com/webhook

# Payload sent on review_ready:
{
  "event": "review_ready",
  "submission_id": "abc-123",
  "deadline": "2026-04-08T12:00:00",
  "review_url": "/submissions/abc-123"
}

Architecture

The platform separates AI evaluation from human governance:

  1. External System — LMS, portal, or API sends a submission
  2. Orchestrator — Creates an issue, triggers the agent's next heartbeat
  3. Agent Harness — Runs the LLM evaluation (GLM-5) and produces structured feedback
  4. HAST + Temporal — Durable workflow waits for human approval (up to 7 days)
  5. Human Review — Approve, reject, or request revision

See GitHub repository for full documentation.
