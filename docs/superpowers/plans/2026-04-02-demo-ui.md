# Demo UI — Landing Page + Pipeline Visualization + Reviewer

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single polished web app that serves as both product demo and reviewer dashboard — lets Pablo/Benito submit an exam, watch the AI pipeline process it in real-time, then act as the reviewer to approve/reject. Replaces the existing `reviewer-ui/`.

**Architecture:** Standalone vanilla HTML/CSS/JS SPA served by nginx. Three-section layout: hero explainer (what this is), live pipeline demo (submit + watch + review), and results history. Polls the HAST API for status updates. Styled to match Lecture's visual language (dark sidebar, white content, blue/purple accents) but branded as "Lecture Agentic AI".

**Tech Stack:** HTML5, CSS3, vanilla JavaScript (no build tools), nginx, Docker

### Task 3: Create the application logic

**Files:**
- Create: `demo-ui/app.js`

- [ ] **Step 1: Create the JS file**

Create `demo-ui/app.js` with these modules:

**1. Config & state:**
```javascript
const state = {
  submissions: [],
  selectedId: null,
  currentFilter: 'review',
  demoSubmissionId: null,
  pollTimer: null,
};

function getConfig() {
  return {
    apiUrl: document.getElementById('apiUrl').value.trim().replace(/\/$/, ''),
    apiKey: document.getElementById('apiKey').value.trim(),
  };
}

function defaultApiUrl() {
  var protocol = window.location.protocol;
  var hostname = window.location.hostname;
  var port = (protocol === 'https:') ? '8443' : '8000';
  return protocol + '//' + hostname + ':' + port;
}
```

**2. Navigation:**
```javascript
function showSection(sectionId) {
  document.querySelectorAll('.section').forEach(s => s.classList.remove('active'));
  document.querySelectorAll('.nav-item').forEach(n => n.classList.remove('active'));
  document.getElementById(sectionId).classList.add('active');
  document.querySelector('[data-section="' + sectionId + '"]').classList.add('active');
}
```

**3. API helpers (reuse escHtml pattern from reviewer-ui):**
- `escHtml(str)` — XSS-safe string escaping
- `apiFetch(path, options)` — fetch with Bearer auth, error handling
- `fetchSubmissions(status)` — GET /api/submissions
- `submitNewSubmission(data)` — POST /api/submissions
- `submitReview(id, decision, notes)` — POST /api/submissions/{id}/review

**4. Demo pipeline:**
- `submitDemo()` — reads form, calls submitNewSubmission with a pre-computed ai_evaluation (simulating what the Hermes agent would produce), shows pipeline, starts polling
- `pollPipeline(submissionId)` — polls GET /api/submissions/{id} every 2 seconds, updates pipeline step states (submitted → evaluating → review → approved/rejected)
- `updatePipelineStep(stepId, state)` — adds CSS classes: `.waiting`, `.active` (pulsing), `.complete` (checked)
- `renderEvaluation(aiEval)` — renders the AI evaluation card with scores, strengths, weaknesses
- `submitReviewInline(decision)` — submits review from the pipeline page, updates pipeline to complete
- `resetDemo()` — clears pipeline, shows form again

**5. Review queue (carry over from reviewer-ui):**
- `loadReviewQueue(filter)` — fetches and renders submission list
- `selectSubmission(id)` — fetches detail and renders in detail panel
- `renderSubmissionList(submissions)` — list items with status badges and scores
- `renderSubmissionDetail(submission)` — full detail with AI eval and action buttons

**6. Initialization:**
```javascript
document.addEventListener('DOMContentLoaded', function() {
  document.getElementById('apiUrl').value = defaultApiUrl();
  // Load saved API key from localStorage
  var savedKey = localStorage.getItem('demoApiKey');
  if (savedKey) document.getElementById('apiKey').value = savedKey;
  // Save key on change
  document.getElementById('apiKey').addEventListener('change', function() {
    localStorage.setItem('demoApiKey', this.value);
  });
  // Nav clicks
  document.querySelectorAll('.nav-item').forEach(function(link) {
    link.addEventListener('click', function(e) {
      e.preventDefault();
      showSection(this.dataset.section);
    });
  });
  // Filter buttons
  document.querySelectorAll('.filter-btn').forEach(function(btn) {
    btn.addEventListener('click', function() {
      document.querySelectorAll('.filter-btn').forEach(b => b.classList.remove('active'));
      this.classList.add('active');
      state.currentFilter = this.dataset.filter;
      loadReviewQueue(state.currentFilter === 'all' ? null : state.currentFilter);
    });
  });
  // Pre-fill demo content
  document.getElementById('demoContent').value = SAMPLE_SUBMISSION;
  // Initial load
  testConnection();
});
```

Include a `SAMPLE_SUBMISSION` constant with a realistic essay text (the same one from demo-routine.sh) and a `SAMPLE_AI_EVALUATION` object with scores/strengths/weaknesses that the demo form submits (simulating what the Hermes agent produces).
